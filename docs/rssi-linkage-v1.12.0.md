## 显示与统计范围

| 入口 | RSSI 行为 |
|---|---|
| 概览 | 实际最低/平均/最高值与有效样本数，可随完整概览复制 |
| 诊断结论 | 元信息显示当前分析范围的 RSSI 统计；心跳信号和弱覆盖小区证据补充实际 RSSI；复制与报告同步 |
| 信号指标 | 图表、跨指标悬停、表格、详情及 CSV 保留原值；HTML 图表使用同一指标视图 |
| 来源对比 | 每个来源分别统计 RSSI，显示最低/平均/最高值与有效样本数，复制包含新增两行 |
| 小区分析 | 按 Cell ID 统计最低/平均/最高值与有效样本数；新增两列，范围列按均值排序、缺测排在有值之后；Markdown/HTML 同步 |
| 事件复盘 | 汇总所选事故观察窗口的 RSSI；邻近 QENG 快照按原有解析规则保留；完整复制及证据 ZIP 一致 |
| 原始日志、事件时间线、标签/未识别统计 | 保持实际日志正文与既有统计口径，不向无 RSSI 证据的记录补造值 |

概览与诊断沿用全局分析范围（来源、时间选区、标签/消息等筛选）。指标快捷条件仅缩小信号指标视图和 HTML 信号图；来源对比按全局筛选分别计算各来源。事件复盘采用自己的观察窗口，可包含全局筛选之外的同来源上下文，界面已标明。

RSSI 只统计实际负数上报值，缺测显示 `-` / 0 个有效样本或当前范围无有效上报，不填零、不从 CSQ 换算。非 LTE 的真实 RSSI 仍保留。新增统计与证据不改变根因规则、判定阈值或小区质量分档；诊断正文去掉了 CSQ 阈值旁的 RSSI 换算说明，以免混淆推算值与实测值。

- `make -j4 check-full windows-all` 通过（`build/rssi-v112-check-build.log`）：单元、真实样本与回归通过；56 个变异全部被抓住，0 存活、0 片段失配、0 异常；x64/x86 构建通过。
- 新断言覆盖来源隔离、时间范围排除、后台接管/卸载、非 LTE、缺测、精确均值、64 位累加、中英文复盘摘要与 RSSI 单独低值不新增弱覆盖归因。
- 实际 HTML 的完整中文/英文报告各有 516 个 RSSI 有效样本，选区有 30 个；小区表头和行列数一致，版本均为 1.12.0。
- 第一条实测事件 ZIP 的 22 条指标中有 9 条 RSSI：最低 -87、平均 -80.9、最高 -69 dBm；独立 ZIP/CSV 校验与报告摘要一致。

- 独立多来源场景通过（`build/rssi-v112-ui-multisource.log`，退出码 0）：同时段来源 A/B 的 RSSI 分别为 -65/-100 dBm，复制不串值；事件复盘、中英文帮助、来源切换、来源对照、原始证据跳转、Markdown/HTML/CSV 导出及 DPI 后对照复制均通过。
- 英文 HTML 在 640 像素 WebKit 中通过（`build/rssi-v112-webkit-narrow.log`）：页面宽度 640，图表内滚动，无页面或文字溢出，五图采样数和时间轴一致，无外部资源。
