# v1.12.0 事件复盘与证据包

> **本地验证产物说明：** 文中 `build/` 下的日志、截图、报告、测试产物及备份是本地生成文件，不随源码分发，发布程序运行不依赖它们；清理后这些路径可能不存在。编译与测试产物可重新生成，历史日志、截图和备份无法原样恢复，需要留档的请先移出 `build/`。

> 本文保留 v1.12.0 的功能与验证记录；当前发布为 v1.12.1，新增工作台功能与验证见 [1.12.1 工作台说明](workspace-v1.12.1.md)。

本版包含事件复盘、证据包、诊断正文选择和键盘操作。发布版本统一为 v1.12.0；断网配对与根因规则保持原有判定条件。

## 入口与操作

- **断网记录**：选中记录后点击右侧「事件复盘」，或按 Enter、使用右键菜单。双击仍跳转故障证据的原始日志行。
- **事件复盘**：上一/下一事件，前后各 0/1/5/10/30 分钟的观察窗口（默认各 5 分钟），事件证据、信号采样、窗口结论三个页签。Ctrl+左右方向切换事件，Escape 关闭。
- 事件表明确显示故障起点、恢复边沿、恢复动作；整行浅色辅助辨识。源文件行与合并行并列；完整消息在下方可选文字区显示，可跳转、加书签。
- 信号采样显示完整日期及 CSQ、RSRP、RSRQ、SNR、RSSI、Cell ID、ΔRX、RAT、所处阶段和来源行号。全部 22 个指标字段仍包含在证据包 CSV 中。
- 「查看信号区间」联动主界面时间范围；主界面的标签、搜索等其他筛选条件仍生效。主界面「恢复全范围」和 Ctrl+0 保留原有行为。
- **诊断结论**：卡片「选择正文」或 F2 打开完整可选文字；上下方向、Home/End 选择卡片，Enter/Space 展开，Ctrl+C 复制当前结论。正文窗口支持鼠标选择、Ctrl+A、Ctrl+C；证据列表可跳转、加书签。整页和卡片原有复制入口保留。
- **信号指标**：「指标说明」集中说明单位、分档、RSSI 实际值、邻近采样时间、快照沿用和参考边界。字体与语言继续独立设置。

## 分析与来源边界

复盘从**当前来源的完整已载入数据**构建事件目录，避开主界面筛选截断；只依据原有规则认可的恢复边沿闭合事故。独立来源不能互相提供恢复证据；跨文件配对仅在用户明确选择同设备续接时启用。未授时与墙钟数据不混作一个时间范围。

指标先从完整来源提取，再截取观察窗口，按原有有效时限保留窗口之前的射频/小区上下文（QENG 信号仅允许紧邻 2 秒内继承），避免与主界面数值不一致。包内指标的 `metrics_basis` 标明此口径；复算窗口前的快照继承仍需要完整原文件。

日志自报时长与边沿时间差可能不同。摘要同时显示「记录时长」与「边沿时间差」，保留引擎原有数值，manifest 另存 `edge_elapsed_seconds`；`self_contained_reported_duration` 仅标识原有的 Down 自包含恢复记录，不能理解为其他恢复行没有自报时长。

窗口结论重新运行现有规则，可能包含前后观察期内的相邻事件，**不作为该次断网的唯一根因**。平台沿用完整来源的识别结果，平台依据可能在观察窗口外，报告和 manifest 单独保留该原文。未触发规则不能证明设备无故障。

新日志载入后清空筛选框会同时取消延迟刷新，避免 450 ms 后误关刚打开的复盘。复盘窗口关闭后释放借用视图；换日志、筛选刷新、切来源、切语言、更换字体、主窗口 DPI 变化和退出时都先关闭相关窗口，避免旧证据或字体继续被使用。

## ZIP 内容

| 文件 | 内容 |
|---|---|
| report.md | 当前语言的事故摘要、平台依据、观察窗口规则及证据 |
| events.csv | 事件时间、类型、来源、原文件行、合并行与完整消息 |
| metrics.csv | 完整 22 列指标，另含阶段及来源定位，共 27 列 |
| parsed-evidence.jsonl | 观察窗口内解析后的正文、标签、级别、时间与来源定位 |
| bookmarks.jsonl | 窗口内书签；无书签时为空文件 |
| manifest.json | 工具版本/编译标识、语言、来源模式、事故边界、观察窗口、数量及平台原文依据 |

保存对话框由主窗口承载，期间禁用复盘窗口，防止选择路径时切换事故；保存或取消后恢复操作。

文件名、标签、证据、AT 返回值保持原文。JSON 转义控制字符与引号；CSV 对日志文本做公式前缀防护，合法负数指标保留数值。限制 64 MiB 的未压缩文件总量及最终 ZIP，超限报错而不截断；原子写入保留失败前的旧目标文件。

以上六文件是基础证据包，不包含原文件字节，`original_bytes_included=false`。工作台补全后，默认勾选“包含所有已载入来源的完整原文件”，额外附原始字节、工作台记录与完整性索引，并支持导入复算；限制和恢复内容见 [工作台说明](workspace-v1.12.1.md)。原文件行号不是解析后重新编号。
