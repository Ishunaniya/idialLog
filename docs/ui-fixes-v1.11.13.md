# dialLog v1.11.13 界面修复核验

> **本地验证产物说明：** 文中 `build/` 下的日志、截图、报告、测试产物及备份是本地生成文件，不随源码分发，发布程序运行不依赖它们；清理后这些路径可能不存在。编译与测试产物可重新生成，历史日志、截图和备份无法原样恢复，需要留档的请先移出 `build/`。

本轮优先处理用户反馈的信号图、表格和筛选输入问题。解析、断网配对和诊断规则没有改动。

## 修复与说明

| 问题 | 原因与本版行为 |
| --- | --- |
| RSRP、RSRQ、SNR 标题没有范围 | 标题补上现有纵轴范围：RSRP -140～-40 dBm、RSRQ -25～0 dB、SNR -20～30 dB。它们是图表显示范围，不是所有模组的有效测量范围；SNR 保留“模组上报值”说明。 |
| 全图与分屏切换后，图像暂时保留旧尺寸 | 尺寸变化没有使整张图失效，系统可能保留旧绘图区域。现在尺寸变化清除旧悬停和命中区域、使整个图表失效；视图切换布局完成后立即重绘子窗口。 |
| 标签统计和断网记录左侧有黑色竖线 | 行高图像列表添加了未初始化的一像素占位位图，非虚拟列表可能将其作为第 0 张图绘制。保留空图像列表提供行高，移除占位位图；截图中黑线消失。 |
| 标签、搜索消息、起止时间输入文字偏上 | 原生单行 EDIT 放在高于文字的控件中。现在按实际字体高度将原生编辑区放在外框中央；外框空白处可点击获得焦点，输入、选区和 IME 继续使用原生控件。 |
| 时间线只用文字颜色表达事件 | 增加“事件”列，采用统一文字色和整行浅色背景。明确区分故障、已恢复、恢复动作、错误、提醒、状态变化、小区/链路、SDK 事件和常规；原标签、消息保持原文。普通 CFUN 标签按状态变化展示，有错误级别时仍标为错误。显示分类不参与根因判断。 |
| 断网记录只靠字体颜色区分时长 | 增加“状态”列，明确已恢复/未恢复。已恢复按 ≤30s、31–60s、>60s 使用浅绿、浅黄、浅红整行背景；未恢复为浅红。页内提示说明分档，不能把时长分档当作故障根因。 |
| 原始日志首条显示行号 2 | EG25 样本第 1 行是 `--- Log opened at ... ---` 会话标记，第 2 行才是首条日志记录。这是原始文件位置，不应重新编号为 1。标题改为“原始行号”，页内说明会话标记、空行和续行的处理。 |

时间线增加列后同步调整复制、完整消息右键入口和详情面板。断网表排序跟随新列的位置，背景随当前排序后的原始事件和当前主题计算；深色和系统高对比配色也保留文字状态。标签统计和断网表末列随窗口宽度调整。

## 核验范围

- `make check` 与 `make check-full` 通过；56 个变异全部被捕获，0 存活、0 片段失配、0 验证异常。
- EG25 真机样本保持 777 条时间线、1399 条指标；首条原始记录仍对应文件第 2 行。单元检查覆盖恢复动作与已恢复的区分、错误级别、普通 CFUN，以及断网时长 30/31/60/61 秒和未恢复边界。
- `make perf` 的 10 万、50 万、100 万行检查通过，包括轻量视图、图表降采样和卸载容量释放。
- Windows x64/x86 交叉构建通过。Wine 界面检查覆盖九页导航、时间线与原始行复制/详情、连续 16 次全图与分屏切换、RSRQ 切换、宽窄窗口、字体设置、取消加载和历史设置。即时切换截图不额外触发重绘，供核对切换本身的结果。
- 截图与运行日志位于 `build/ui-v1.11.13-captures/` 和 `build/ui-v1.11.13-*.log`。截图人工核对了范围标题、完整时间、行底色、黑线消除和输入框对齐。

GUI 仅在 Wine 中验证，尚未在真实 Windows、全部 DPI 和字体组合中验证。图表缩放、来源对比、列设置和中英文切换仍属于后续工作，参见 [上一轮界面核验与后续改进](ui-review-v1.11.12.md)。
