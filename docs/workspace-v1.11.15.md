## 来源查看与对照

加载多份文件或包含多份日志的压缩包后，默认独立查看按时间定序后的第一份来源。时间范围栏左侧“来源 / 对照”菜单可切换来源；概览、诊断、图表、时间线、断网、指标、标签、原始日志和小区分析使用当前来源。解析审计仍针对整份输入，概览和报告中的完整来源摘要也保留整份输入统计。

独立来源之间不配对断网起止或流量计数。原始行号仍是合并输入中的全局证据行号，不随来源或筛选重新编号。来源平台识别使用该来源完整记录，不受时间/标签/消息条件影响。

确认全部文件属于同一设备时，可人工选择“同设备续接”，恢复合并分析。文件名只是来源标识，工具不会根据名称猜测设备身份；当前不能分别将多份文件编组为多台设备。跨文件事故配对仍遵守现有解析器的来源/重启/时基边界规则。

“来源对照”打开 A/B 窗口，可分别选择来源、返回查看 A 或 B，或复制完整对照。16 项字段包含观测起止、观测时长、解析行、指标样本、断网次数、未恢复次数、已闭合断网总时长、两种可用率、最长首次联网等待，以及 RSRP/CSQ 的均值、极值与样本数。均值按整数显示；无观测或无有效信号使用 `—`。未闭合断网不估算恢复时长，可用率继续采用现有观测证据规则。

对照按当前图表选区、手工起止时间、标签和消息条件重算，分别统计每个来源。指标页 Cell/RAT/CH/DENY 快捷条件只影响指标展示，不改变诊断或来源对照。不同窗口和不同样本量的百分比不适合直接排名。当前对照是统计表，尚未提供曲线叠加或完整设备身份管理。

时间范围栏保留完整起止日期；当前来源显示在文件说明和菜单中，避免长文件名挤占日期。“恢复全范围”清除时间条件，保留当前来源和标签/消息条件。新日志重置为第一份独立来源；加载失败或取消保留原文档、来源和选区。

## 指标列设置

信号指标页的“显示列”菜单提供常用、射频、注册、流量、AT 健康和全部六种预设，也可逐列勾选。时间列固定保留，其他列按原顺序显示。默认全部 22 列；设置保存在当前用户注册表，重启后继续使用。

隐藏仅改变列表列宽，不删除数据。完整详情、整行/多行复制和 CSV 始终保留 22 列；不改变图表、诊断、筛选或计算结果。

## 中英文与字体

右上角“字体”（英文界面为 `Aa`）菜单包含简体中文和 English。切换后更新导航、控件、表头、图表、空状态、诊断标题/依据/建议、复制结果及 Markdown/HTML 报告；保留来源选择、时间与搜索条件、列设置和用户字体。语言设置独立保存，切换语言不重新解析日志或改变根因判断。加载期间暂不可切换语言，以保持后台任务文案一致。

文案由稳定 ID 和离线词条管理；数字、日期、单位保留。原始日志、标签、路径、文件名、AT 返回码和原证据不翻译，因此英文页面或报告仍可能出现中文日志证据。CSV 保留稳定英文列名，工程评价与 AT 健康说明采用当前语言。

界面字体与等宽日志字体仍可分别选择、保存及恢复默认。英文长标签重新布局；本版没有强制覆盖用户字体。

复核同时修复了单来源对照在改变时间范围后沿用旧统计的问题，以及 Markdown 建议正文漏翻译。筛选字段更新通知返回后再刷新按钮状态，避免同步读取正在更新的编辑框；导出菜单与消息命令共用同一处理入口。

主窗口 DPI 改变时会关闭来源对照窗口，避免重建字体后弹窗仍引用旧字体；重新打开对照保留当前来源、筛选条件和统计口径。

## 验证范围

- `make check` 覆盖原有解析、真实日志基线、断网/诊断、虚拟表与图表检查，以及来源隔离、选区交集和文档交换/释放。两份时间重叠的合成来源分别钉死 2 秒/7 秒断网、CSQ 18/8、RSRP -95/-115，避免跨来源串配。
- 离线词条生成校验检查 ID、非空英文和格式参数一致性。语言单元检查遍历 62 份样本的 160 条诊断标题、依据与建议，英文生成正文不残留中文，原始证据另行保留。
- `make check-full`：56 个变异全部捕获，0 存活、0 片段失配、0 验证异常。`make perf`：10 万、50 万、100 万行检查通过。性能数字依赖运行主机，不代表所有 Windows 设备的等待时间。
- Windows x64/x86 交叉构建；Wine 界面回归检查九页导航、原有图表选区、复制/详情、加载取消/重载、宽窄窗口与字体，并增加列预设、中英文切换、来源查看/续接、A/B 对照复制和 Markdown/HTML/CSV 导出。另发送 144 DPI 变化消息，核对对照窗口关闭、重新打开、来源保持及复制统计一致；该检查不替代真实多显示器验证。

界面截图在 `build/ui-v1.11.15-captures/`，检查日志在 `build/v15-*.log`。GUI 仅在 Wine 中验证，尚未覆盖真实 Windows、全部 DPI、字体和辅助技术组合。合成来源检查不能替代真实多设备日志验证。

字体选择与保存已在独立界面运行中检查；最终回归可用 `DIALLOG_UI_SKIP_FONT_DIALOGS=1` 跳过重复字体枚举，适用于资源紧张的共享主机。测试 Wine 配置的桌面等目录链接必须有效：本次曾因旧链接目标不存在而导致系统文件对话框目录为空，修复为测试配置内的目录后重测。此环境修复仅位于忽略入库的 `build/`。
