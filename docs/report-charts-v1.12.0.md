## 旧报告与程序的差异

旧 HTML 采用固定 920 个横向桶，每桶保留峰谷与全局首尾；并非每 N 个点取一个。绘制时 X/Y 坐标取整，图高为 250，时间轴仅标首尾，工程说明直接压在曲线上。不同指标各用自身起止时间，没有对齐，缺少真实采样空缺断线、孤立点标记与 RSSI。

实测 `samples/rtms_eg25/dial_20260630_000026.log` 有 1399 条指标记录，其中 CSQ 1359 点、RSRP/RSRQ 各 563 点、SNR/RSSI 各 516 点。这些序列均低于旧预算的 1842 点，旧报告也保留了全部有效点；该样本的观感差异不能归因于采样不足。更密集的日志会触发降采样。

旧报告使用全部解析指标，而程序使用当前指标视图；还存在报告把未知 CSQ=99 当作有效值的问题。本版共用 `reportedSignalSeries`，统一当前来源、筛选、指标快捷条件、有效范围与稳定时间排序。其他报告章节仍遵循原有分析范围，图表明确标注使用当前指标视图。

## 新报告行为

- CSQ、RSRP、RSRQ、SNR、RSSI 分图展示，共享完整日期时间轴。已有时间选区时使用选区端点。
- 图表保留两位小数坐标，使用矢量直线与圆角连接；图高增加，工程参考线说明移到独立右栏。
- 明示「原始点 / 绘制点」。8194 点以内保留全部样本；更大序列采用 4096 桶峰谷降采样，单序列最多 8194 个绘制点。降采样点均来自真实记录，不插入测量值。
- 从原始序列识别超过 10 分钟的采样空缺，路径在空缺处断开，即使降采样后空缺边界不在输出中也不跨越连线。
- 孤立点、少量采样及路径起点可见；密集点在悬停时显现并通过原生 SVG 标题展示实际保留点的时间和值。这是初版的静态 SVG 行为；工作台补全后，启用脚本时使用完整有效序列寻找邻近采样。
- 红色浅带标示断网区间。RSSI 只使用实际负数上报值，轴随极值扩展；不从 CSQ 换算，也不添加统一好坏阈值。非 LTE 的 RSSI 仍可显示，其他四项沿用原有 LTE 工程参考口径。
- 窄屏横向滚动，避免图表文字随窗口一起挤小；打印时恢复自适应宽度。报告为单个离线 HTML，无外部脚本或网络资源。逐行时间推定标记仍见指标表及 CSV。
