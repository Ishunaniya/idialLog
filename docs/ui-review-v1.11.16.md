# v1.11.16：语言入口、诊断预览与信号图

本次核验从 v1.11.15 源码、现有日志和实际窗口截图出发。主观上的“AI 味”不能量化；确认的问题是语言藏在“字体”菜单、诊断正文和多条证据全部展开，以及分屏绘图区偏矮。原 1280 像素宽截图中三条曲线的绘图区各约 50 像素高，整数坐标的 GDI 折线没有抗锯齿。这些是显示问题，不能据此推断日志的采样精度不足。

## 使用方式

- 左侧导航栏底部的 **语言 / 字体**（英文 `Language / Fonts`）菜单首先列出简体中文和 English，下方保留界面字体、等宽日志字体和恢复默认。入口固定在版本信息上方，菜单向上展开；文件说明恢复完整宽度。较矮窗口使用单行导航标题，保留全部九个页面和设置入口，避免与版本信息重叠。该位置调整仍保持 v1.11.16。
- 诊断默认展示原文的依据和建议预览，并标明“预览”。点击单条 **展开详情** 可看完整依据、建议和证据；顶部 **展开全部** 同时展示平台识别证据和所有结论。**精简显示** 恢复预览。
- 信号图中间一栏可切换 **RSRP / RSRQ / RSSI**，CSQ、SNR 仍独立显示。没有对应样本的按钮不可选择。RSSI 的单位是现有解析模型的 dBm，直接使用已有负值样本，不从 CSQ 换算、不补零。指标表、详情和 CSV 原有 RSSI 列继续保留。
- 同版本修订：鼠标悬停提示同时列出 **CSQ、RSRP、RSRQ、RSSI、SNR**，不受中间图当前指标影响。每项有值时保留自己的采样日期、时间与单位；没有该指标时显示“暂无数据”，最近样本距离准线超过十分钟时显示“附近无采样”。仍查询真实样本，不插值或补值；修订保持 v1.11.16。
- 分屏自动分配更大的图表高度，并随窗口尺寸调整；手工拖动分隔条后保留用户设置，受图表和表格最小空间约束。小窗口容不下三张图时仍会显示空间不足提示，可收起筛选、切换图表全页或增加窗口高度。

## 数据与诊断口径

诊断仍由本地固定规则生成。展示标题去掉重复的“全量日志历史汇总”前缀，来源和时间范围继续在页首、复制和报告中标注；预览只是原文截取，并保留原文中出现的源码直证、日志直证、样本实证和推断标签，不重新生成摘要。复制、右键复制和报告使用完整正文与全部证据，不受折叠影响。

RSSI 在真实日志中已有记录，例如 AG35 样本 `real_ag35_1.32.0_sd.log` 的 `RSSI:-48`，以及 artery 样本中的 `RSSI:-53`。原有解析器也可能继承两秒内紧邻 QENG 返回的 RSSI；图表使用现有指标采样时间，不把继承值宣称为新的独立测量。不保证每个平台、固件或日志都提供 RSSI。

RSSI 默认显示轴为 -120～-20 dBm，出现超出该范围的实际值时扩展坐标轴；这只是显示范围，不是协议上报范围或通用故障阈值。RSSI 不新增质量分档或断网归因。

曲线使用系统 GDI+ 的抗锯齿直线和浮点绘制坐标，保持已有峰谷降采样、真实点悬停及超过十分钟的采样空缺断线。单点样本加大标记，仍保留原时间位置。不使用样条拟合，不增加采样，不修改秒级指标时间。GDI+ 初始化失败时回退到原 GDI 绘制；不需要安装额外运行时。绘图区分别保留图表/分屏两种尺寸的缓存，数据、时间范围、指标、DPI、配色或尺寸变化会使对应缓存失效；悬停与选区保持实时绘制。

## 验证与边界

检查包括 RSSI 原值/时间/缺失值、显示轴极值与整数边界；诊断 UTF-8 预览、截取位置之后的推断标签保留及标题数字保留；原有解析和真实日志基线。语言检查继续遍历 62 份样本、160 条完整诊断，并检查区间和独立来源标题的完整英文翻译。完整规则变异检查的 56 个变异全部检出，存活、统计不匹配和异常均为 0；x64、x86 构建通过。

百万行基准增加 RSSI 路径：99800 个实际指标样本生成 99800 个 RSSI 点，1920 像素宽降采样为 1921 点，检查首尾时间和原值、规模及关闭时释放。

界面回归覆盖诊断展开前后的完整复制一致性、宽窄布局、分屏/图表切换、RSRP/RSRQ/RSSI 切换与悬停、语言切换、来源对照和三种导出。截图位于 `build/ui-v1.11.16-captures/`，构建和检查日志位于 `build/v16-*.log`。

展开前后完整复制的 3232 个字符逐字一致；Wine 跨进程滚动范围返回 0 时不能作为展开高度断言，因此另核验实际展开截图。
