## 入口和使用

1. 打开日志后，点击顶部“来源” → “设备、复核与前后对比…”，窗口有“设备归属”、“复核记录”和“前后 / 设备对比”三个页签。单文件也可以使用。
2. 在设备编组中选中来源，填写设备 ID、固件和配置后保存。相同非空 ID 表示人工确认同设备；空值表示身份未确认。文件名和平台识别不会自动决定设备身份。来源菜单可以切到某个设备组，也保留单来源查看和原有续接模式。
3. 在对照页分别选择 A/B 来源或设备组，填写完整起止日期时间，再计算。可以比较同一来源的两个时期、同设备的两份日志，或不同设备。五指标叠加图支持 CSQ、RSRP、RSRQ、SNR、RSSI，A 实线、B 虚线；默认按各自区间起点对齐，也可按真实时间对齐。支持复制统计和导出交互 HTML。
4. 在事件复盘中点击“复核与备注”，或在诊断结论的独立文字视图中填写状态与备注。可选待复核、已确认、已处理。复核记录页可双击或按 Enter 再编辑；人工记录不改变自动结论，复制摘要和报告会附带记录。
5. 在信号指标图的绘图区使用滚轮缩放、Shift+滚轮或中键拖动平移。程序选区联动时间线、指标和结论；顶部“恢复全范围”或 Ctrl+0 清除时间范围。
6. 在复盘窗口导出证据 ZIP，默认附上所有已载入来源的完整原文件。通过“来源”或“导出”菜单的“导入证据包…”恢复，也可以直接打开该 ZIP。

## 统计口径

对照展示解析记录、样本、观测时长、断网次数和未闭合数、累计断网时长、运行/全程可用率、最长启动耗时，以及五信号指标的有效数、均值、最小值、P10/P50/P90 和最大值；差值为 B−A。可用率差值单位为百分点。没有有效依据的值显示 —。

区间边界可能缺少启动或恢复证据，因此每侧独立沿用现有证据判断。百分位按有效采样秩取值，不按时间加权。RSSI 仅统计实际负数上报值，不从 CSQ 换算，不赋统一健康阈值；SNR 显示实际 dB。不同窗口时长、采样密度和业务负荷可影响差值，差值本身不证明固件或配置导致改善。

恢复统计保留日志实际上报的标签、阶段和层级/动作；没有上报的层级不补推。它是动作记录数量，不等同于恢复成功次数。

## 记录保存与身份

记录保存在 `%LOCALAPPDATA%\dialLog\workspaces\<摘要>.json`，以本批来源内容、名称及同名同内容的重复序号建立稳定身份；批次摘要使用排序后的身份。重开同一批、同内容和名称的来源可以恢复，文件选择顺序改变不影响批次。改名、修改内容或换成另一批文件会使用不同记录；证据包携带原身份，可在导入后恢复记录。

保存采用原子替换；损坏的现存记录会报错并禁止覆盖。人工备注按原文保存，不随语言切换翻译；工具生成标题和状态随语言切换。复制和导出保留完整依据与证据。

诊断卡片的简洁视图按完整句子呈现，保留推断、限制和否定结论，不再按固定字符数截断。完整正文仍可展开、选择、复制和导出。这是呈现层压缩，不是重写全部诊断规则，也不改变证据强度。

## 完整证据包

基础六文件之外增加 `originals/*.log`、`workspace.json`、`package-index.json`。索引包含原身份、SHA-256、观察范围、来源/设备选择和原来源行号书签。导入先核对 ZIP 路径、重复项、CRC、文件清单、SHA-256、来源身份和记录关联，再载入解析；不会向磁盘解压包内路径。

原文件内容保留 BOM、CRLF 和所有原始字节。普通压缩输入保留其日志条目的未压缩字节，不声称保存原压缩容器；粘贴输入保存剪贴板转换后的 UTF-8 文本。导出会重新核对磁盘来源，来源已修改或丢失时拒绝完整包导出，避免旧分析搭配新原文。

包含的是所有已载入来源，而不只是当前事故选区。完整包最多包含 1000 个原来源；单个原来源最多 256 MiB，完整包未压缩总量和最终 ZIP 最多 512 MiB。每个生成的证据文本文件最多 64 MiB；不附原文的基础包，其未压缩总量和最终 ZIP 也分别限制为 64 MiB，超限报错而不截断。仍受普通输入与批量文本限制。导入恢复完整日志、工作台状态、选定来源/设备、观察范围和书签，诊断按当前工具规则重新计算；历史导出正文在包中保留。旧六文件包没有原文，只能查看报告，不能完整复算。

## 离线 HTML

图表嵌入完整有效采样，绘制时仍保留峰谷预算；框选、滚轮缩放、Shift+滚轮/中键拖动平移、恢复按钮和 Ctrl+0 共享时间轴。悬停按当前鼠标时间寻找各指标的实际邻近值，最多相差 600 秒，显示各自真实采样时间；没有样本会明确提示。对照图同时显示 A/B 原始日期时间，即使横轴使用相对秒数。

超过 600 秒的原始采样空缺仍断线。点击或键盘选中断网色带可以定位事件表；框选同时筛选事件表。离线交互只改变图表和事件显示，已导出的统计与诊断保留导出时范围，页面明确说明这一点。HTML 无外部脚本或网络资源；脚本禁用时保留静态 SVG 和正文。
