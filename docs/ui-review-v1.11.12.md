## 已确认并修复

| 问题（源码确认） | 本版行为 |
| --- | --- |
| 概览/结论自绘文字无法整页复制，依据与建议没有复制入口 | 页内复制按钮、Ctrl+C、卡片右键菜单；结论可逐条复制，保留依据/建议/证据；概览包含可用率、观测范围、统计和输入文件信息 |
| 时间轴最小步长为一小时，短日志可能没有任何刻度；跨日只显示时分 | 按秒/分钟/小时/天选择刻度；始终保留起止时间；每个刻度显示日期和秒 |
| 指标、时间线、断网表省略年份 | 完整年月日与时分秒；时间列扩宽；推定时间保留 ~，指标 CSV 同步保留 |
| 悬停固定优先取 CSQ 的时间，还把邻近的其他指标写在同一行 | 取距离最近的真实采样；各项值列出自身时间，超过 10 分钟没有采样时说明缺失；浮窗限定在图表窗口内 |
| 缺失指标仍占据空图区，单个采样几乎不可见 | 缺失图区收拢；少量采样与新曲线段显示点标记；分屏优先为已有图区分配空间 |
| 固定最小图表高度没有考虑实际图区数量，低矮窗口可能出现图区挤压甚至反向矩形 | 最小高度按实际图区数量计算；高度不足时说明如何释放空间，不绘制被挤压的曲线 |
| 跨过很长的采样空缺直接连线，容易误读为持续观测 | 超过 10 分钟的真实采样空缺断开曲线；空缺不额外生成断网结论；空缺识别在降采样前完成 |
| 长标题没有换行，证据测量宽度与绘制宽度不同，时钟跳变/空结论说明可能截断 | 按实际可用宽度测量并换行；复制按钮预留空间；证据卡高度按真实绘制宽度计算 |
| 概览时间、平台、可达率和覆盖率挤在一行；卡片注释越界 | 时间范围独立显示；完整统计放入可换行、可复制的明细卡；指标卡约束文字绘制区域 |
| 导航、按钮、图表使用 XOR 焦点矩形，视觉上出现黑框 | 导航鼠标选择不再绘制焦点框；键盘焦点保留主题色轮廓；按钮/图表也统一改为轮廓 |
| 长页滚动条从 HIWORD 取位置，超过 65535 时可能跳错 | 使用 SCROLLINFO 的完整跟踪位置；窗口变化后同步有效位置 |
| 字体写死，DPI 更新后继续恢复默认字体 | 界面/等宽日志字体分别选择、即时应用、保存到 HKCU；DPI 变化继续使用选择的字体；可恢复默认 |
| 分屏静态分隔条会残留原页面文字，菜单箭头依赖特定字形 | 分隔条独立填充背景并绘制拖动把手；下拉箭头直接用 GDI 绘制 |
| 概览重绘重复遍历日志 | 在文档刷新时计算仪表盘统计，重绘复用缓存；指标卡点击可直接打开断网/审计/信号页 |
| 控件文本读取按预估长度保留尾部空字符 | 使用 GetWindowTextW 的实际返回长度；避免混合 ANSI/Unicode 控件的长度预估影响筛选或设置 |

## 文案处理

“工作台 · 研判与处置”“数据 · 时序与原始证据”等改成直接的栏目名称；“结论将在这里形成”“本工具不臆测”等说明改为具体状态。诊断页显示规则命中数，不把命中数量称为已确认的故障数量。原诊断规则中的事实、推断、适用平台和证据等级仍保留；本轮没有逐条重写全部规则正文。

可用率和工程参考的解释仍有必要：没有首次联网或启动证据时不显示无依据的 100%；CSQ/RSRP/RSRQ/SNR 分档不能独立证明断网根因。

## 下一轮优先项（尚未实现）

1. **图表缩放与时间区间选择**：框选一次断网前后，联动时间线、指标和结论；提供一键恢复全范围。现在只有全范围图和全局筛选。
2. **来源选择与对比**：多文件图表可按来源单独查看；明确是同设备续接还是不同设备对照。现有多日志概览已有逐来源统计，不能当作完整的设备对比工作台。
3. **列显示设置**：指标表有 22 列；常用、射频、注册、流量、AT 健康按任务选择列，保留完整详情和导出。当前可横向滚动，窄窗口不可能同时展示全部列。

## 工作台适合增加什么

- **事件复盘**：针对某次断网串起异常起点、恢复动作、信号变化、业务恢复与证据行，减少在多页之间来回查找。
- **复核状态与备注**：已确认、待复核、已处理；人工备注独立于自动结论，不改变日志事实。
- **同设备前后对比**：配置/固件变更前后，比较可用率、启动耗时、断网次数、恢复层级和信号分布。设备身份需要明确指定。
- **证据包**：把选定事故区间、结论、原始证据、书签和工具版本打包，方便交给现场或研发复核。现有 Markdown/HTML/CSV 导出只是基础。

不建议先堆更多“健康评分”或无证据的 AI 综合判断；上述功能更直接地减少排障操作。
